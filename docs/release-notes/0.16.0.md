This is an early release. Please report what you hit and attach the log (F1 > System > Log).

**You need your own disc image:** Metroid Prime 2: Echoes USA (`G2ME01`), PAL (`G2MP01`), or Trilogy (`R3ME01` USA, `R3MP01` PAL). No disc image or game assets are included.

## What changed

- **Special menu** (F2, or both stick clicks on a pad): an in-game menu in the game's own look for save states, the memory card, game options, cheats, items and warps. Thanks to rivyr. #132
- **Beam doors can stay unlocked** (F1 > Game > Unlocks > Unlock beam doors once opened, off by default): a Dark, Light or Annihilator door you opened stays blue. #129
- **Only charged shots use ammo** (F1 > Enhancements, off by default): uncharged Dark, Light and Annihilator shots are free. #130
- **Precise stick deadzones** (F1 > Controls > Controller settings, off by default): the deadzone sliders become the only deadzone, for smaller ones than the game allows. #131
- **Resolution scale up to 8x**, enough to supersample a 4K display.
- **Android 10:** the shader cache no longer fails with "disk I/O error". #98
- **Mouse clicks** work on a message box after closing F1 with Fire rebound. #126
- **Separate menu buttons:** the scan box shows the right button from the start. #127
- **Menus** no longer lose pieces when one closes while it is still loading. Thanks to rivyr. #125
