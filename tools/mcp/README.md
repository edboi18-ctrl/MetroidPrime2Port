# tools/mcp

`echoes_mcp.py` is an MCP server for modding and building on the port: Prime World Editor's script
templates, your disc's rooms (read-only), the mods folder and the running game. `workshop.py` holds its
logic (standard library only). Setup, the tool list and the roadmap: [docs/MCP_WORKSHOP.md](../../docs/MCP_WORKSHOP.md).
Tests: `tests/mcp_workshop.py` (ctest `mcp_workshop`).
